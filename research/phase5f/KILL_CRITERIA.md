# Phase 5F — Kill Criteria and Required Verdict

Status: PRE-REGISTERED DRAFT

The project must be allowed to fail.

## K1 — MINIMAL does not improve RAW
If MINIMAL creates no preregistered material improvement over RAW on HARD:
- structured dependency-evidence thesis is weak;
- do not proceed as if Claim Gate value is established;
- narrow/pivot.

## K2 — FULL does not improve MINIMAL
If FULL has no repeatable independent benefit:
- do not defend Phase-5 complexity;
- 5R should delete/internalize unnecessary identities/models/protocol/synthesis wrappers.

## K3 — Simple Graph+Time matches current synthesis
If B1 is practically equivalent to B1S:
- simplify/remove propagation synthesis architecture;
- retain only evidence semantics with independent value.

## K4 — Claim verification would be format policing only
If structured evidence/claim fields do not reduce real unsupported claims, provenance errors, counterevidence loss, or incorrect non-abstention:
- rethink Claim Gate thesis before Phase 6.

## K5 — Controlled results are order/repetition unstable
If later counterbalanced/repeated experiments are materially unstable without representable context:
- freeze stronger causal interpretation;
- redesign experiment/context model.

## K6 — Cross-environment behavior is unrepresentable
If systemd/kernel/distro changes alter conclusions and schema cannot represent relevant context:
- narrow scope or evolve schema from observed gaps.

## K7 — No measurable operator/agent value
If later operator/agent evaluation shows no measurable value beyond standard tools/baselines:
- pivot to fault-ground-truth/evaluation framework or stop reasoning direction.

## K8 — External benchmark reveals missing required information
If surviving schema loses required external evidence:
- evolve schema based on observed gap, not speculation.

## Required Phase-5F Verdict

Choose exactly one:

### A — THESIS VALIDATED, FULL COMPLEXITY JUSTIFIED
Structured evidence passes and FULL adds repeatable value over MINIMAL.

### B — THESIS VALIDATED, MINIMAL EVIDENCE SUFFICIENT
Structured evidence passes; FULL does not add enough value. Proceed to deletion-first 5R.

### C — PARTIAL VALUE, NARROW THE THESIS
Some evidence discipline is useful, but scope must be narrowed.

### D — NO MATERIAL EVIDENCE VALUE, PIVOT
Structured evidence does not materially improve reasoning. Pivot toward Fault Lab/evaluation/evidence runtime if justified.

### E — STOP DEPENDENCY/REASONING DIRECTION
The evidence/dependency reasoning direction does not justify continued investment.

## Invalid Evaluation Exception

“More data is needed” is not a verdict.

It is acceptable only when a **specific experimental-validity condition failed**, such as label leakage, mismatched cases, provider/model change, scorer bug, or protocol violation. Then document invalidation and perform a versioned rerun without treating invalid results as thesis evidence.
